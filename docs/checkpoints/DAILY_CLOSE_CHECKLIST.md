# EMF Daily Close-Down Checklist

## Purpose

Preserve the engineering state at the end of each session.

## Source Control

Run:

git status

Confirm:
- main branch
- up to date with origin/main
- clean working tree

## Build

Run:

dotnet build

Record:
- success/failure
- warnings
- errors

## Tests

Run:

dotnet test

Record:
- total tests
- passed
- failed
- skipped

## Architecture Checkpoint

Record:
- completed work
- design decisions
- new models
- new contracts
- new services

## Next Starting Point

Record:
- latest commit
- next task

## Environment

Verify:
- VM status
- Azure resources
- shutdown state

Confirm:

nothing to commit, working tree clean
