Completed shared rules
- Claim type, Claimed condition, and Basis centered beneath Prepared Using.
- Visible metadata/source boundary: thin rule and spacing attached to the final
  metadata paragraph; keep-with-next retains the source attachment.
- Demonstrated known label/value fragments recover source tokens only. Long
  prompts use the full width; Reason for Study stays paired with its value.
- Explicit lab/imaging headers and two agreeing data rows establish fixed columns
  with unchanged row associations. Ragged/PowerForm/unanchored rows remain uninferred.
- Known problem-list/date-time fragments normalize whitespace without changing values.
- Source images align left, use zero added indentation/padding and maximum
  proportional fit, preserve original literature/native-fallback margins and
  orientation, and keep running headers/footers outside the image area.
- Automatic medical-literature figure/table enlargements are labeled supplements
  following the complete original page. They never replace the original view.

Deterministic detection: caption-grid-v1
- Raster separation: 12 points. Minimum region: 60 x 35 points. Region area must
  be less than 75% of page area. Native point geometry supplies scale; without it,
  the shorter raster axis is assigned 612 points for conservative detection only.
- Numbered Figure/Fig./Table captions: <=24-point vertical distance, >50% overlap
  of the shorter horizontal span, and exactly one candidate per caption.
- Figures: native graphics provenance, >=100 non-text ink pixels and >=20%
  non-text ink after masking native glyph boxes.
- Uncaptioned tables: >=3 horizontal and >=2 vertical thin rules, >=80% coverage,
  and >=4 populated cells across >=2 rows and columns. Each populated cell needs
  >=2 separated interior marks. Empty plot grids and solid rectangles fail.
  Maximum rule thickness: max(3 pixels, shorter region side / 25).
- Safe padding: six points, clamped to the original page. Every interior crop
  edge must be exact opaque white, including faint marks; page edges retain ink.
- Required enlargement: >=1.35x original-page display scale. Insufficient gain,
  confidence, unsafe boundaries, and overlapping selections are rejected.
- Confidence is a High/Low rule category, not a calibrated probability.
- Extraction is a lossless pixel subset. No OCR, redraw, interpolation, or numeric
  correction. The supplement box is 6.5 x 8 inches with proportional fit and a
  separate visible-label allowance; running headers/footers remain outside.

Frozen provenance and lifecycle
Every eligible candidate binds source artifact/page; exact oriented privacy-masked
raster SHA-256; masking/rotation transform version; raster dimensions/orientation;
applied quarter-turn; top-left half-open pixel rectangle; detection method/version/
confidence; selection state/rejection reason; relative magnification; exact drawing
size in EMUs; selected crop SHA-256; and renderer build. The enclosing presentation
also binds the render profile and immutable source-snapshot hash.

The compiled DOCX audit records Detected or Selected. Preparation verifies source
raster identity, bounds, every crop pixel, and drawing dimensions before recording
Selected as Frozen in the snapshot. Rejected candidates remain Detected and never
render. FigureTableRegions is an immutable value collection with JSON round-trip
value equality. The optional extension is omitted from historical presentations,
preserving their hashes. The immutable source snapshot V1 wire contract is unchanged.

Preserved reprint = materialize the frozen DOCX/PDF. No detection, recropping, or
reinterpretation. A newly prepared presentation may run detection under its version.
